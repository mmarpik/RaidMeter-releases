# Raid Meter

A damage, healing and trigger meter for EverQuest raids, by Mazilla AB. It reads the game's log files only:
it never touches the game, sends keystrokes or reads its memory.

**Download:** [the latest RaidMeter-win-Setup.exe](https://github.com/mmarpik/RaidMeter-releases/releases/latest)
(Windows 10 2004 or newer, about 86 MB, nothing else needed).

- Installs for your Windows user only, no admin prompt, with a Start-menu shortcut.
- Updates itself: a new version downloads in the background, and installs when you close the meter or
  click **Restart now**. It never restarts on its own in the middle of a raid.
- Windows may say "Windows protected your PC" the first time: choose **More info → Run anyway**.
- In the game, turn logging on with `/log on`.

This repository only holds the installers and update packages.
